# 💎 Titanium Finance - Akıllı Gelir Gider Tablosu & AI Ekstre Çözümleyici

Profesyonel metalik panel tasarımı, Google Gemini AI tabanlı karmaşık kredi kartı ekstre ve gelecek taksit ayrıştırıcısı, ve bilgisayar ile telefon arasında anlık canlı bulut eşitleme (Cloud Sync) sunan yeni nesil kişisel bütçe yönetim sistemi.

---

## 🌟 Öne Çıkan Özellikler

### 1. 🤖 Yapay Zeka Destekli Ekstre & Gelecek Taksit Çözümleyici (Gemini AI Vision)
- **Kredi Kartı Seçimi:** Hangi kartın ekstresi olduğunu seçin (örn: *İş Bankası Batı*, *Axess*, *Garanti* vb.).
- **Karmaşık Ekstre Muhakemesi:** Türk bankalarının kafa karıştırıcı gösterimlerini (örneğin *Toplam Kart Borcu* ile *Gelecek Taksitler Toplamı* yazan ekranları) yapay zeka otomatik anlar:
  $$\text{Cari Ay Borcu} = \text{Toplam Borç} - \text{Gelecek Taksitler}$$
- **Aylara Göre Taksit Dağıtımı:** Gelecek ayların taksitlerini tespit edip o aylardaki taksitleri otomatik toplar.
- **Onay & Düzeltme Mekanizması:** Yapay zeka asla tablonuzu doğrudan körü körüne değiştirmez. Hesaplama gerekçesini şeffafça açıklar; kullanıcıya düzenlenebilir bir kontrol tablosu sunar. Dilerseniz rakamları değiştirebilir, *"Üzerine Ekle"* veya *"Yerine Yaz"* seçenekleriyle tek tıkla tablonuza işleyebilirsiniz.
- **Hazır Test Modu:** Fotoğraf yüklemeden sistemi anında deneyebilmeniz için *"Örnek İş Bankası Ekstresi"* ve *"Örnek Garanti Ekstresi"* butonları mevcuttur.

### 2. 📱 Cihazlar Arası Canlı Bulut Eşitleme (PC ↔ Telefon ↔ Tablet)
- **GitHub Gist Senkronizasyonu:** Bütçe veritabanınız tamamen ücretsiz, sınırsız ve gizli olarak kendi GitHub Gist'inizde saklanır.
- **QR Kod ile 1 Saniyede Telefona Eşleştirme:** Bilgisayar ekranındaki QR kodu telefonunuzun kamerasıyla taratın; hiçbir şifre girmeden telefonunuzdaki tarayıcıda aynı tablo açılır ve birbirine bağlanır.
- **Otomatik Eşitleme (Auto-Sync):** Bilgisayarda bir harcama girdiğinizde otomatik buluta yüklenir; telefondan sayfayı açtığınızda en son güncel veri karşınızda olur!

### 3. 🎨 Yönetici Metalik Panel & Lüks Koyu Titanyum Tema
- Özel fırçalanmış çelik, koyu titanyum ve platin hatlara sahip profesyonel finans paneli.
- Yapay zeka ile üretilmiş yüksek çözünürlüklü finansal dokulu arka plan (`assets/financial_metallic_bg.jpg`).
- Yapışkan (sticky) ay sütunları ve mobil telefonlar için optimize edilmiş kaydırma düzeni.
- Sürükle-bırak (Drag & Drop) ile sütunların yerini değiştirme, tüm aylara tek tıkla değer uygulama (🔽), dinamik satır/sütun ekleme/çıkarma.

### 4. 📈 Finansal Göstergeler & Grafikler
- Yıllık toplam gelir, toplam gider, net birikim ve tasarruf oranı KPI kartları.
- Aylık net nakit akışı ve harcama dağılımı (Doughnut) grafikleri.

## 🚀 GitHub ve GitHub Pages'e Yükleme (Adım Adım)

Bu projeyi internet üzerinden kendi kişisel siteniz olarak yayınlamak ve telefonunuzdan açmak için:

1. **GitHub'da Yeni Bir Repo Açın:**
   - GitHub hesabınıza girip `butce-tablom` (veya istediğiniz bir isimle) yeni bir repository oluşturun (Public seçin).

2. **Dosyaları Yükleyin:**
   Terminal veya komut satırından bu klasörün içine girip:
   ```bash
   git init
   git add .
   git commit -m "Titanium Finance ilk surum"
   git branch -M main
   git remote add origin https://github.com/KULLANICI_ADINIZ/REPO_ADINIZ.git
   git push -u origin main
   ```
   *(Veya GitHub web arayüzünden "Upload files" diyerek bu klasördeki tüm dosyaları sürükleyip bırakabilirsiniz).*

3. **GitHub Pages'i Açın:**
   - Reponuzun üst menüsünden **Settings** -> sol menüden **Pages** kısmına gelin.
   - **Branch** kısmından `main` seçip **Save** butonuna basın.
   - 1-2 dakika içinde siteniz yayında olacaktır! (Adres: `https://kullaniciadiniz.github.io/repo-adiniz/`)

## 🔑 Google Gemini API Anahtarı Nasıl Alınır? (Ücretsiz, 30 Saniye)

Yapay zeka ekstre okuyucu için Google'ın resmi ücretsiz Gemini API'si kullanılır:
1. [Google AI Studio](https://aistudio.google.com/app/apikey) adresine gidin.
2. Google hesabınızla giriş yapıp **"Create API key"** butonuna tıklayın.
3. Çıkan anahtarı kopyalayıp bütçe tablonuzdaki **"Ayarlar & API"** sekmesine yapıştırın ve **Kaydet**'e basın.
4. Artık dilediğiniz ekstre veya taksit ekran görüntüsünü yükleyip anında çözebilirsiniz!

## 📱 Cep Telefonunda Gerçek Bir Mobil Uygulama Gibi Kullanma İpucu

- Sitenizi cep telefonunuzda (iPhone Safari veya Android Chrome) açın.
- Tarayıcı menüsünden:
  - **iPhone (Safari):** Paylaş (Share) simgesine dokunun -> **"Ana Ekrana Ekle"** (Add to Home Screen) deyin.
  - **Android (Chrome):** Üç nokta menüsüne dokunun -> **"Ana Ekrana Ekle"** (Add to Home Screen) deyin.
- Artık telefonunuzun ana ekranında banka uygulaması gibi tek tıkla tam ekran açılan akıllı bir bütçe uygulamanız olacaktır!
